# Agent Guidelines & Technical Instructions for WP Calculator

> **Примітка для AI-агентів (Note for AI Agents):** Власник репозиторію буде часто називати цей документ **"інструкція"**. Коли користувач пише **"інструкція"**, **"згідно інструкції"**, або **"дивись в інструкцію"**, він має на увазі саме цей файл (`AGENTS.md`). Завжди звіряйтеся з цим файлом та неухильно дотримуйтесь його вимог. Дивіться пункт 0 щодо правил внесення змін до нього.

## 1. Головні принципи роботи AI-агентів (Core Operating Principles)

0. **Ніколи не редагувати цю інструкцію без прямого погодження:**
   - AI-агенти не мають права самостійно змінювати, скорочувати, розширювати чи видаляти будь-які пункти цієї інструкції.
   - Якщо агент вважає, що потрібно щось додати чи уточнити — спершу опишіть пропозицію користувачеві у повідомленні та дочекайтеся прямої згоди.

1. **Два режими виконання — Прямі вказівки vs Обговорення/Критика:**
   - **Пряма вказівка** ("зроби X", "додай Y", "зміни Z", "поправ W"): виконуйте негайно без зайвих уточнень "чи впевнені ви?". Зробіть роботу та повідомте конкретний результат.
   - **Обговорення або відкритий відгук** (користувач запитує думку або вказує на проблему без прямого таска): проаналізуйте, запропонуйте варіанти та дочекайтеся згоди.

2. **Залізобетонний захист від втрати даних (Data Loss Prevention — СУВОРО):**
   - **Найголовніша вимога:** Створені користувачем матеріали та збережені вироби **НІКОЛИ НЕ ПОВИННІ ЗНИКАТИ** при оновленні версії коду чи редагуванні плагіна.
   - Будь-яка зміна коду збереження зобов'язана зчитувати й об'єднувати всі історичні ключі опцій: `wood_calc_store_v3`, `wood_calc_store_v4`, `wood_calc_store_v2`, `wood_calc_store`, `wood_calc_store_backup`.
   - Обов'язкова наявність локального дзеркала в браузері (`localStorage` ключ `wood_calc_local_mirror_v2`). Якщо сервер повертає порожній результат або сталася мережева помилка, скрипт автоматично відновлює дані з дзеркала назад у базу.
   - Кнопка **«💾 Бекап»** у шапці калькулятора для скачування JSON-файлу завжди повинна залишатися робочою.

3. **Суворе дотримання фірмового дизайн-коду:**
   - Кольори сайту tomchik.com.ua:
     - Темний графіт (шапка, кнопки, підсумок): `--tc-dark: #24272a`
     - Фірмовий зелений акцент: `--tc-green: #95b504`
     - Темно-зелений hover: `--tc-green-dark: #7e9c02`
     - Світло-зелений фон блоків розрахунку: `--tc-green-light: #f4f8e7`
     - Червоний акцент для видалення: `--tc-danger: #dc2626`
   - **Жодних стандартних синіх браузерних чекбоксів:** усі чекбокси стилізовані зеленим кольором (`accent-color: #95b504; width: 18px; height: 18px;`).
   - **Жодних стандартних системних вікон confirm():** підтвердження видалення елементів реалізуються виключно через модальні вікна у дизайні сайту.

4. **Розкладка та мобільна адаптивність (Responsive Layout):**
   - **На комп'ютерах (> 900px):** 2 стовпчики: лівий (калькулятор і вироби), правий 360px («Довідник матеріалів»).
   - **На мобільних пристроях (<= 900px):** «Довідник матеріалів» **ОБОВ'ЯЗКОВО переміщується на самий верх** (`order: -1`), щоб користувач міг спочатку обрати або налаштувати матеріал.

5. **Правила Drag-and-Drop (Зміна порядку виробів):**
   - Перетягування рядків таблиці активується **ВИКЛЮЧНО через ручку ⠿ (`.wc-drag-handle`)**.
   - Поля введення кількості та назви виробів не повинні тягнути рядок — користувач повинен вільно виділяти цифри та текст мишкою.
   - Під час перетягування місце вставки підсвічується зеленою горизонтальною лінією (`drop-above` / `drop-below`), а змінений порядок одразу фіксується в базі даних.

6. **Вимоги до режиму «Накладна для скріна»:**
   - При переході в режим накладної ховаються всі зайві панелі.
   - У шапці накладної відображається ТІЛЬКИ: заголовок `РОЗРАХУНОК ЗАМОВЛЕННЯ` та поточна дата (жодних сторонніх назв магазину чи логотипів).
   - Кнопка **«← Вийти з режиму накладної»** завжди розташовується **ОКРЕМО ПІД БЛОКОМ НАКЛАДНОЇ**, щоб не потрапляти на скріншот клієнту.
   - Панель вибору колонок накладної дозволяє гнучко вмикати/вимикати показ колонок перед формуванням знімка.

7. **Логіка розрахунків:**
   - Розміри виробів вводяться в **міліметрах (мм)**.
   - Розрахунок площі: в **см²** (`(довжина * ширина) / 100`).
   - Вартість за 1 см² підтримує дробові числа будь-якої точності (наприклад, `0.20123 грн`) без примусового округлення в полях введення.
   - **Ціни доданих виробів є фіксованими:** зміна ціни матеріалу в довіднику не змінює вартість уже створених виробів у каталозі.

8. **Структура плагіна та назви:**
   - Назва репозиторію та плагіна: `wp-calculator`.
   - Головний файл: `wp-calculator.php`.
   - Архів релізу: `wp-calculator.zip` (всередині архіву коренева папка `wp-calculator/`).
   - Пункт у меню адмінки: **«Калькулятор виробів»**.
   - Шорткод: `[wood_calculator]`.
